# Setup
Create a public GitHub repository named RayanMirza under RayanMirza. Upload all files including the hidden .github directory (git push is recommended). Enable Actions and read/write workflow permissions under Settings > Actions > General. Run Build profile manually once. The daily schedule refreshes the contribution radar using the workflow-provided `GITHUB_TOKEN`; never commit tokens.

Edit config/tech-stack.json to add an object with name, mark, color and type to any category; cards wrap automatically. Marks are text approximations, not official logos. Edit features.json to toggle the supported visual features, theme.json to change the accent, and profile.json to change identity. Run node scripts/generate.mjs locally to rebuild the README. Commit configuration or script changes to trigger the build. The external stats card depends on a third-party service.
