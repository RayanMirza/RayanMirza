# Setup
Create a public GitHub repository named RayanMirza under RayanMirza. Upload all files including the hidden .github directory (git push is recommended). Enable Actions and read/write workflow permissions under Settings > Actions > General. Run Build profile and Contribution snake manually once. Daily schedules follow. The terrain requires GitHub GraphQL access; if the default token fails, adjust the workflow to use a suitable personal access token stored as a repository secret. Never commit tokens.

Edit config/tech-stack.json to add an object with name, mark, color and type to any category; cards wrap automatically. Marks are text approximations, not official logos. Edit projects.json to add real repository URLs. Edit features.json to toggle the supported features, theme.json to change the accent, and profile.json to change identity. Run node scripts/generate.mjs locally to rebuild. Commit config changes to trigger the build. The snake workflow runs independently even if its display is disabled. The external stats card depends on a third-party service. The terrain is an animated isometric translation, not a true rotating camera. GitHub rendering and remote workflows have not been tested.
